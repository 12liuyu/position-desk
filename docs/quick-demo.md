# 一分钟体验持仓执行卡

这是可照着操作的图文演示，不是自动生成投资建议，也不是录屏视频。所有示例均为虚构。

## 0-15秒：装好并调用

在要使用Skill的项目目录中运行README里的安装命令，再向Codex发送：

> 请用 $position-desk 演示持仓执行卡，只使用虚构数据，不读取我的账户。

Agent应先运行无界面的检查入口，并明确输出`demo`模式；只有在存在交互桌面时才打开演示窗口。

不使用Agent也能体验：下载仓库，安装Python后运行 `python -B app.py --demo`。

## 15-30秒：先看操作，再看价位

选择“高开回落”，主操作为示例“受阻减100股”。卡片同时显示可卖数量限制、开盘基准、受阻价与人工确认条件，不能只看标题就操作。

![实际桌面演示窗口，数据全部虚构](demo.jpg)

## 30-45秒：看颜色与依据

`26.00(+1.96%)`为红色；`24.25(-4.90%)`为绿色；`25.50(0.00%)`为灰色。涨跌幅基于演示收盘25.50，与按成本25.00计算的盈亏和3%示例提醒线不同。

点击“完整分析”查看完整条件和理由；选择“突破走强”时，界面变成另一条预案，但不会声称突破已经发生。

## 45-60秒：理解更新边界

点击“重读数据”。提示应为本地结构与金额校验，不是“券商账户采集完成”。关闭一次弹窗不等于卖出，退出应用则不再跟踪。

下一步若要使用自己的数据，请按 [数据格式](data-format.md) 提供私人目录中的`account.json`。不提交真实账户截图、密钥或持仓到GitHub。

## 试用反馈

请记录系统/Python版本、是否装成功、卡在哪一步、最难理解的一个字段。公开Issue只贴虚构复现样本；真实金额和账户信息应删去。使用人数、复用情况和效果尚未验证，不以Star或安装测试次数代替真实用户反馈。
